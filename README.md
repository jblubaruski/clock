# Clock

## Overview

This application is an analog clock that can either show the current time or tick from a user-set time.

The program will create a log file in "%MyDocuments%\PlaypenSoftware\Clock" where errors and notifications are logged.

### System Requirements

Clock requires a computer with an x86 processor and an installation of Windows 10 or later.

## Download and Installation

Download clock-v1.0-win-x64.zip in Releases and extract all files to a directory of your choice.
Double click Clock.exe to run the program.
You can also create a shortcut to Clock.exe by right clicking on Clock.exe, select "show more options" and select "create shortcut".
